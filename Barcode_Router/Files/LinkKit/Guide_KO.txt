Barcode_Router 연동 가이드 - 단계 설명 (화면 왼쪽 버튼 ① ~ ⑥)
[번호] 줄 아래부터 다음 [번호] 전까지가 그 단계의 글입니다. 이 파일을 고치면 Router 를 다시 빌드하지 않아도 바로 바뀝니다.

[1]
Router ⇄ 검사 프로그램을 잇는 가상 COM 짝을 만듭니다. (검사 프로그램 1개당 1짝)

아래 버튼 → [복사] → 관리자 cmd 에 붙여 넣기

  처음          : 1 → 3 → 2 → 4
  com0com 있음  : 2 → 4

※ Router 쪽 COM 은 ⑤, 검사 프로그램 쪽 COM 은 ② 에서 씁니다.

[2]
검사 프로그램이 Router 를 쓸지 정하는 파일입니다. 없으면 원래대로 동작합니다.

Yes 체크 → [RouterLink.mdb 저장] → EquipmentSetting.mdb 와 같은 폴더에

바코드 포트는 원래 설정 EquipmentSetting.mdb 의 BarcodeReaderPort 에 넣습니다 (아래 칸 참고).

※ Router 없이 쓰려면 RouterLink = No (또는 파일 삭제) + 포트를 원래 리더 COM 으로.

[3]
모든 검사 프로그램이 같은 연동 클래스를 씁니다. 파일 안은 고치지 않습니다.

  1. [clsRouterLink.vb 저장] → 프로젝트의 클래스 폴더에
  2. Visual Studio : 프로젝트 오른쪽 클릭 > 추가 > 기존 항목 > clsRouterLink.vb

※ 이미 있으면 새 파일로 바꿔 넣습니다.

[4]
검사 프로그램에 1줄을 넣습니다.

모든 검사 프로그램이 같은 방식입니다 : 바코드 COM 수신 → 검사 → END 회신

이름 확인 → [복사] → 첫 줄에 적힌 위치 (SerialPort1_DataReceived 의 끝) 에 붙여 넣기

※ 바코드를 키보드 (HID) 로만 받던 프로그램은 먼저 바코드 COM 을 읽어 여는 코드
   (FAM3_MAIN_HIPOT 와 같은 SerialPort1 / cls101_ComRS232C / BarcodeReaderPort) 를 넣습니다.

※ 연동이 실패해도 검사는 멈추지 않습니다 (로그만 남음).

[5]
Router 에 이 검사 프로그램을 등록합니다.

  1. COM 설정 : 분기 대상 [+ 추가]
       COM = ① 의 Router 쪽 / 통신설정 = 검사 프로그램과 같게 / 프로세스명 = exe 이름
  2. 분기 조건 설정 : [+ 신규] → 분기 COM, 조건 (예 MSCODE LIKE F3*) → [판단 시험]
